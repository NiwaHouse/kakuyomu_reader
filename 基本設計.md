# 基本設計書 - スピークブラウザ (Speak Browser) - Web小説・Webページ読み上げブラウザ

## 1. システムアーキテクチャ概要
本アプリは **クリーンアーキテクチャ** と **MVVM (Model-View-ViewModel)** パターンを融合し、**機能単位（Feature-Based）** のフォルダ構成を採用します。

```text
+--------------------------------------------------------------------+
|                         UI Layer (Compose)                         |
|  [ReaderScreen] <--> [ReaderViewModel]                            |
+------------------------------------+-------------------------------+
                                     |
+------------------------------------v-------------------------------+
|                       Domain Layer (UseCases)                      |
|  [ProcessTappedParagraphUseCase]   [SpeakParagraphUseCase]         |
|  [AutoPlayNextUseCase]             [WebViewScriptInjectorUseCase]  |
+------------------+---------------------------------+---------------+
                   |                                 |
+------------------v-----------------+   +-----------v---------------+
|    Feature: Playback (Core/Service)|   | Feature: SiteParser (Plug)|
|  [NovelPlaybackService]            |   | [NovelSiteParser (IF)]    |
|  [TtsEngineManager]                |   |   ├── KakuyomuSiteParser  |
|  [PlaybackController]              |   |   ├── NarouSiteParser     |
|  [AndroidX MediaSession]           |   |   └── GenericSiteParser   |
+------------------------------------+   +---------------------------+
                   |                                 |
+------------------v---------------------------------v---------------+
|                    Core Layer (Model & Common)                     |
|  [NovelParagraph] [PlaybackState] [TextChunker] [RubyFilter]       |
+--------------------------------------------------------------------+
```

## 2. モジュール & レイヤー設計

### 2.1. Core層 (`core/`)
- **`core/model`**:
  - `NovelParagraph`: 読み上げ対象の段落データ（`id: String`, `text: String`, `rawText: String`, `index: Int`, `siteType: SiteType`）。
  - `PlaybackState`: 再生状態（`IDLE`, `BUFFERING`, `PLAYING`, `PAUSED`, `STOPPED`, `ERROR`）。
  - `PlaybackSpeed`: 再生速度（0.5f 〜 3.0f）。
  - `SiteType`: 対象サイト種別（`KAKUYOMU`, `NAROU`, `GENERIC`）。
- **`core/common`**:
  - `TextChunker`: 長文を句読点や改行で一定文字数以内のチャンクに分割するユーティリティ。
  - `RubyFilter`: 文字列中のルビ表現の補助クリーナー。

### 2.2. Feature: SiteParser (Plugin層) (`feature/siteparser/`)
- **`NovelSiteParser` (Interface)**:
  - `canHandle(url: String): Boolean`: 指定URLを処理可能か判定。
  - `getInjectionScript(): String`: WebViewに注入するタップ監視・ルビ除去・DOM抽出JSを返却。
  - `getHighlightScript(paragraphId: String): String`: 指定段落をハイライトするJSを返却。
  - `getNextParagraphScript(currentParagraphId: String): String`: 次の段落を取得・発火するJSを返却。
- **実装クラス**:
  - `KakuyomuSiteParser`: カクヨム (`kakuyomu.jp`) 用パーサー。`.widget-episode-body p` 等のDOMをターゲットとし、`<rt>`を除去。
  - `NarouSiteParser`: 小説家になろう (`syosetu.com`, `ncode.syosetu.com`) 用パーサー。`#novel_honbun p` 等をターゲットとする。
  - `GenericSiteParser`: 汎用Webページ用パーサー。`<p>`、`<article>`要素をターゲットとする。
- **`ParserRegistry`**:
  - URLから適切な `NovelSiteParser` を検索・解決するレジストリ。

### 2.3. Feature: Playback (Core層) (`feature/playback/`)
- **`TtsEngineManager`**:
  - Android標準 `TextToSpeech` の初期化、言語設定（日本語）、速度設定、キュー制御（`QUEUE_FLUSH`, `QUEUE_ADD`）、`UtteranceProgressListener` による発話終了コールバック管理。
- **`NovelPlaybackService` (Foreground Service)**:
  - バックグラウンド再生を持続するフォアグラウンドサービス。
  - Media3 `MediaSession` を構築し、通知バー（Notification）に再生/一時停止/次段落/前段落の操作パネルを提供。
- **`PlaybackController`**:
  - ViewModelとServiceをバインドし、双方向で再生イベント・状態をやり取りするコントローラー。

### 2.4. Feature: Bookmark & History (`feature/bookmark/`)
- **`BookmarkHistoryRepository`**:
  - SharedPreferencesを用いたお気に入り（タイトル・URL・作成日時）、閲覧履歴（タイトル・URL・閲覧日時）、読み上げモード（CONTAINER / PARAGRAPH）、親階層数設定の永続化管理。
- **`BookmarkHistoryDrawer` / `DrawerTabRow`**:
  - `ModalNavigationDrawer` 内に配置されるサイドドロワーUI。お気に入り一覧、履歴一覧、設定タブ（読み上げ方式・親階層数スライダー）を描画。

### 2.5. Feature: Reader (UI層・ViewModel) (`feature/reader/`)
- **`ReaderViewModel`**:
  - `ReaderUiState`（URL、読込進捗、現在再生段落、再生状態、再生速度、お気に入り、履歴、読書モードなど）を `StateFlow` で管理。
  - JS Bridgeからのイベントを受信し、UseCase経由で再生要求を発行。
- **`AndroidBridge` (`JavascriptInterface`)**:
  - WebView内JSから `onParagraphClicked`、`onContainerParagraphsExtracted`、`onNextParagraphFound`、`onEndOfEpisode` を受信。
- **Jetpack Compose UI**:
  - `ReaderScreen`: `ModalNavigationDrawer` と `Scaffold` を統合した画面全体の構成。
  - `ReaderWebView`: `AndroidView` を用いたWebViewコンポーネント。
  - `ReaderTopBar`: メニュー（☰）、戻る/進む/更新、URL入力、お気に入り登録（☆）、ホーム（🏠: Google）。
  - `ReaderControlBottomBar`: 再生/一時停止、前へ/次へ、速度変更スライダー、現在読み上げ文表示。

## 3. 主要シーケンス

### 3.1. タップ読み上げ〜自動連続再生・次話自動遷移シーケンス
```text
User / UI         WebView (JS)            AndroidBridge       ReaderViewModel       PlaybackService (TTS)
 |                     |                        |                    |                        |
 |-- タップ ---------->| (ルビ除去・DOM解析)    |                    |                        |
 |                     |-- onParagraphClicked ->|                    |                        |
 |                     |                        |-- onParagraphTap ->|                        |
 |                     |                        |                    |-- speak(paragraph) --->| (再生開始)
 |                     |<-- highlightParagraph -|                    |<-- State: PLAYING -----|
 |                     |                        |                    |                        |
 |                     |                        |                    |<-- onUtteranceDone ----| (段落再生完了)
 |                     |<-- requestNextParagraph|                    |                        |
 |                     |-- onNextParagraphFound>|                    |                        |
 |                     |                        |-- onNextParagraph->|                        |
 |                     |                        |                    |-- speak(next) -------->| (次段落再生)
 |                     |                        |                    |                        |
 | (エピソード末尾)    |-- onEndOfEpisode ----->|                    |                        |
 |                     |                        |-- onEndOfEpisode ->|                        |
 |                     |                        |                    |-- [次話リンク探索・遷移]
 |                     |<-- loadUrl(nextUrl) ---|                    | (速度 PlaybackSpeed 維持)
 | (新ページ読み込み)  |-- onPageFinished ----->|                    |                        |
 |                     |<-- injectScript -------|                    |                        |
 |                     |<-- extractAll ---------|                    |                        |
 |                     |-- onExtracted -------->|                    |                        |
 |                     |                        |-- onExtracted ---->|-- speak(p1, speed) --->| (次話第1段落から再生継続)
 |                     |                        |                    |                        |
 | (最終話到達時)      |-- onEndOfEpisode ----->| (次話なし)          |                        |
 |                     |                        |-- onEndOfEpisode ->|-- speak("作品の末尾です")|
 |                     |                        |                    |<-- onUtteranceDone ----| (アナウンス完了)
 |                     |                        |                    |-- stopService() ------->| (サービス/通知終了)
```
