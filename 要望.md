#Android (Kotlin) での実装ですね！

「**WebViewでタップしたHTML要素のテキストを取得し、Android標準のTTS（TextToSpeech）で読み上げる**」最小構成のプロトタイプ（PoC）コードを作成しました。

カクヨムなどの小説サイトにおけるルビ（`<ruby>`タグ）の二重読み上げ問題（例：「漢字かんじ」と読まれてしまう問題）を解決するJavaScriptフィルタリングも組み込んでいます。

### 3. メイン処理 (`MainActivity.kt`)

WebViewへのJavaScript注入、Bridge（`JavascriptInterface`）経由のテキスト受取、およびTTS読み上げ処理を実装したコードです。

```kotlin
package com.example.webnovelreader

import android.annotation.SuppressLint
import android.os.Bundle
import android.speech.tts.TextToSpeech
import android.util.Log
import android.webkit.JavascriptInterface
import android.webkit.WebView
import android.webkit.WebViewClient
import android.widget.Button
import android.widget.TextView
import android.widget.Toast
import androidx.appcompat.app.AppCompatActivity
import java.util.Locale

class MainActivity : AppCompatActivity(), TextToSpeech.OnInitListener {

    private lateinit var webView: WebView
    private lateinit var tvStatus: TextView
    private lateinit var btnStop: Button

    private var tts: TextToSpeech? = null
    private var isTtsReady = false

    override fun onCreate(savedInstanceState: Bundle?) {
        super.comOnCreate(savedInstanceState)
        setContentView(R.layout.activity_main)

        webView = findViewById(R.id.webView)
        tvStatus = findViewById(R.id.tvStatus)
        btnStop = findViewById(R.id.btnStop)

        // TTSの初期化
        tts = TextToSpeech(this, this)

        // 停止ボタンの処理
        btnStop.setOnClickListener {
            stopSpeech()
        }

        // WebViewの設定
        setupWebView()
        
        // カクヨムのトップ画面（テスト用）をロード
        webView.loadUrl("https://kakuyomu.jp/")
    }

    @SuppressLint("SetJavaScriptEnabled")
    private fun setupWebView() {
        webView.settings.javaScriptEnabled = true
        
        // AndroidネイティブコードとJSを連携するインターフェースを登録
        webView.addJavascriptInterface(WebAppInterface(), "AndroidBridge")

        webView.webViewClient = object : WebViewClient() {
            override fun onPageFinished(view: WebView?, url: String?) {
                super.onPageFinished(view, url)
                // ページ読み込み完了時にクリック監視用のJavaScriptを注入
                injectClickHandlingScript()
            }
        }
    }

    /**
     * DOM要素のタップイベントを拾い、ルビなどを除外したテキストをAndroid側に送るJavaScript
     */
    private fun injectClickHandlingScript() {
        val script = """
            (function() {
                if (window.hasInjectedNovelReader) return;
                window.hasInjectedNovelReader = true;

                document.addEventListener('click', function(e) {
                    let target = e.target;
                    
                    // タップされた要素のクローンを作成してルビ(<rt>)を除去（「漢字かんじ」と読まれるのを防ぐ）
                    let clone = target.cloneNode(true);
                    let rts = clone.querySelectorAll('rt');
                    rts.forEach(rt => rt.remove());

                    let text = clone.innerText || clone.textContent;

                    if (text && text.trim().length > 0) {
                        // 文字列が長すぎる場合の過度な選択を防ぎ、タップした要素テキストを送る
                        AndroidBridge.onElementClicked(text.trim());
                    }
                }, true);
            })();
        """.trimIndent()

        webView.evaluateJavascript(script, null)
    }

    /**
     * JavaScriptから呼び出されるブリッジクラス
     */
    inner class WebAppInterface {
        @JavascriptInterface
        fun onElementClicked(text: String) {
            runOnUiThread {
                Log.d("WebNovelReader", "抽出テキスト: $text")
                tvStatus.text = "読み上げ中: ${text.take(15)}..."
                speakText(text)
            }
        }
    }

    /**
     * TTSでテキストを再生
     */
    private fun speakText(text: String) {
        if (!isTtsReady) {
            Toast.makeText(this, "TTSの初期化が完了していません", Toast.LENGTH_SHORT).show()
            return
        }

        // 既存の音声を停止して新しいテキストを再生
        tts?.stop()
        
        // QUEUE_FLUSH: 現在再生中の音声をキャンセルしてすぐに指定テキストを再生
        tts?.speak(text, TextToSpeech.QUEUE_FLUSH, null, "NovelUtteranceId")
    }

    private fun stopSpeech() {
        if (tts?.isSpeaking == true) {
            tts?.stop()
            tvStatus.text = "停止しました"
        }
    }

    // TTSの初期化コールバック
    override fun onInit(status: Int) {
        if (status == TextToSpeech.SUCCESS) {
            val result = tts?.setLanguage(Locale.JAPANESE)
            if (result == TextToSpeech.LANG_MISSING_DATA || result == TextToSpeech.LANG_NOT_SUPPORTED) {
                Log.e("TTS", "日本語言語パックがサポートされていません")
            } else {
                isTtsReady = true
                // 読み上げ速度調整（1.0が標準。1.2等で少し早口に）
                tts?.setSpeechRate(1.0f)
            }
        } else {
            Log.e("TTS", "TTS初期化失敗")
        }
    }

    override fun onDestroy() {
        // メモリリーク防止のためTTSを解放
        tts?.stop()
        tts?.shutdown()
        super.onDestroy()
    }
}

```

## コード解説とポイント

1. **`JavascriptInterface` による連携**
`addJavascriptInterface` を使うことで、WebView内のJavaScriptから `AndroidBridge.onElementClicked(text)` のようにAndroid側の関数を直接実行できるようにしています。
2. **ルビ（`<rt>`タグ）の除外**
カクヨムなどの小説サイトでは、`<ruby>漢<rt>かん</rt>字<rt>じ</rt></ruby>` という構造になっています。JS側で `clone.querySelectorAll('rt').forEach(rt => rt.remove());` を行うことで、**ふりがな部分を消去した漢字のみ（またはふりがなのみ）のクリーンなテキスト**をAndroid側に送出しています。
3. **`TextToSpeech.QUEUE_FLUSH`**
ユーザーが次の段落をタップした際に、前の段落の読み上げを中断して**即座にタップした新しい文章に切り替わる**ように設定しています。

## 本格開発（プロダクション実装）に向けた拡張ステップ

実際のアプリとして完成度を高めるためには、次の要件を追加実装していくのがおすすめです。

1. **長文の分割再生（Chunking）**
* Android標準TTSは一回の `speak()` に渡す文字数が多すぎると途中で切れることがあります。段落が長い場合は `。` や `\n` で区切って `QUEUE_ADD` でキューに追加していく処理を組み込みます。


2. **自動連続読み上げ機能**
* 1つの段落を読み終わったら、JavaScript側で `nextElementSibling`（次の段落要素）を自動取得して順番に読み上げていく連続再生ループ機能。


3. **Foreground Service & Media3 (ExoPlayer)**
* アプリをバックグラウンドに回したり画面をロックしても読み上げを維持できるよう、`ForegroundService` 内でTTSを制御し、ロック画面や通知領域に「停止 / 再生」パネル（`MediaNotification`）を出せるように構成します。
